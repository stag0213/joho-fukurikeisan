💡 72の法則 (Rule of 72)

複利運用で元本が「2倍」になるまでの年数の目安は 72 ÷ 年利(%) で計算できます。

現在の設定（年利 5.0%）では、約 14.4 年 で資産が2倍になります！
  • 単利（直線増）: 利息が常に最初の元本に対してのみ計算されるため、毎年一定額（等差数列）で増えます。
  • 複利（曲線増）: 増えた利息が次の期の元本に組み込まれるため、後半になればなるほど爆発的（等比数列・指数関数的）に増えます。

単利と複利の数理モデル

現実の現省をコンピュータで計算できるよう「数式（モデル）」で表現する方法を学びます。

1. 単利モデル（Simple Interest）

一次関数・等差数列

元本 $P$ に対してのみ、毎期一定割合 $r$ の利息がつきます。過去に発生した利息は次期の利息計算に含まれません。

$A_n = P \times (1 + r \times n)$

・$P$: 元本 (Principal)

・$r$: 年利率 (Rate, 5%なら0.05)

・$n$: 経過年数 (Years)

・$A_n$: $n$年後の総額 (Amount)

📊 グラフに描くと「直線（一次関数 $y = ax + b$）」になります。

2. 複利モデル（Compound Interest）

指数関数・等比数列

各期末の利益（利息）を次の期の元本に加えて再投資します。「利息が利息を生む」モデルです。

$A_n = P \times (1 + r)^n$

・$P$: 元本

・$r$: 年利率

・$n$: 経過年数（**指数**の位置に着目！）

・$A_n$: $n$年後の総額

📈 グラフに描くと上向きに反り立つ「曲線（指数関数 $y = a \cdot b^x$）」になります。

アルゴリズム（繰り返し処理でのシミュレーション）

プログラムでは、1年ごとの状態変化を繰り返し処理（forループ）で表現することができます。

// 1年ごとの資産シミュレーション処理例 (JavaScript)

let principal = 1000000; // 初期元本 100万円

let rate = 0.05; // 年利5%

let compound = principal;

let simple = principal;


for (let year = 1; year <= 30; year++) {

simple += principal * rate; // 単利：元本固定で利加算

compound = compound * (1 + rate); // 複利：前期末の総額に掛け算

}
