# 高校情報Ⅰ シミュレーション教材：単利 vs 複利

## 高等学校情報科「情報Ⅰ」における単元「モデル化とシミュレーション」の学習を目的とした、Webベースのインタラクティブ教材アプリです。

資産形成における「単利」と「複利」の計算を通じて、現実の現象を数理モデル（一次関数・指数関数）として捉え、コンピュータによるシミュレーションやパラメータ変化の影響を視覚的かつ直感的に体験できます。

### 🌟 主な機能と特徴

1. インタラクティブ・シミュレーター

パラメータ設定:

元本（初期投資額）: 10万円 ～ 1,000万円

年利率（金利）: 0.1% ～ 15.0%

運用期間: 1年 ～ 50年

毎年の追加積立（発展設定）: 0万円 ～ 120万円/年

リアルタイム・グラフ描画: Chart.jsを活用し、元本・単利・複利の資産推移を折れ線グラフで即座に可視化。

主要指標（KPI）カード: 30年後の総額や増減、複利効果の差額（単利の何倍か）をリアルタイム更新。

72の法則（Rule of 72）の自動計算: 設定した利率で資産が2倍になる目安年数を表示。

データ出力: 年別の試算結果を CSV ファイルとしてダウンロード可能。

2. モデル解説・数式

数式モデルの可視化:

単利モデル: 一次関数・等差数列 $A_n = P \times (1 + r \times n)$

複利モデル: 指数関数・等比数列 $A_n = P \times (1 + r)^n$

MathJaxによる美しい数式描画: LaTeX形式で数式を表示。

アルゴリズム例: JavaScriptによる繰り返し処理（for ループ）のサンプルコードを掲載。

3. 理解度チェッククイズ

学習内容の定着を確認するための3問の多肢選択式クイズ。

自動採点機能と解説フィードバック付き。

4. 授業ワークシート案

学習指導要領に沿った「探究課題」のテンプレート。

印刷または画面参照しながら授業内でそのまま活用可能。

### 📚 学習指導要領との関連

教科・科目: 高等学校 情報科「情報Ⅰ」

大項目: (3) コンピュータとプログラミング / (4) 情報通信ネットワークとデータの活用 または モデル化とシミュレーション

単元目標:

事象を抽象化し、一次関数・指数関数などの「数理モデル」に落とし込む考え方を理解する。

条件（パラメータ）を変えた際の結果の変化をシミュレーションによって観察・分析する。

モデル化の限界（現実世界における税金・物価変動・金利変動等の考慮要素）について考察する。

### 🚀 使い方・動作環境

動作環境

モダンなWebブラウザ（Google Chrome, Microsoft Edge, Safari, Firefox 等）

インターネット接続（CDN経由でライブラリを読み込みます）

実行方法

index.html ファイルをローカル環境にダウンロードします。

index.html をダブルクリック（またはブラウザにドラッグ＆ドロップ）して開くだけで動作します（サーバー構築不要）。

### 🛠 使用技術（テクノロジー）

HTML5 / JavaScript (ES6+)

Tailwind CSS: UIデザイン・レスポンシブレイアウト

Chart.js: 資産推移の動的グラフ描画

MathJax v3: TeX/LaTeXによる数式レンダリング

Lucide Icons: アイコン表示
